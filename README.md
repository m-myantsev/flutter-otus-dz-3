# Otus.Food

Книга рецептов на Flutter

## Описание

Список блюд с фото и временем приготовления, состав, пошаговый разбор, избранное и комментарии.

Рецепты приходят с сервера и сохраняются локально, и без интернета приложение продолжает работать.

## Возможности

- Лента рецептов с фото, названием и временем приготовления
- Страница рецепта, включающая состав, шаги приготовления с отметками, избранное, комментарии
- Создание рецепта, состоящее из названия, ингредиентов и шагов
- Загрузка рецептов с сервера и отправка созданных обратно в API
- Локальная база для того, чтобы всё загруженное и созданное переживало перезапуск
- Работа без интернета на локальных данных
- Галерея фото рецепта, которые можно снять камерой или выбрать из альбома
- Распознавание объектов на фото с рамками и подписями

## Как это устроено

Источником данных выступает [foodapi](https://foodapi.dzolotov.pro). Сервер отдаёт рецепты, шаги,
ингредиенты и единицы измерения отдельными коллекциями, а приложение собирает из них полные рецепты.

Схема работы с данными:

1. при запуске сразу показывается то, что лежит в базе, и экран не ждёт сеть;
2. параллельно выполняется запрос к серверу, и успешный ответ замещает в базе серверные записи;
3. интерфейс перечитывает данные из базы, поэтому показанное всегда совпадает с сохранённым.

Если сервер недоступен, шаг 2 просто не выполняется и приложение остаётся на локальных данных.
Рецепт, созданный без интернета, сохраняется локально с отрицательным идентификатором, чтобы
последующая синхронизация его не перезаписала.

## Фото и распознавание

На странице рецепта есть лента фото.
Плитка `Добавить фото` предлагает сфотографировать блюдо или выбрать снимок из альбома.
Нажатие на миниатюру открывает полноэкранный просмотр со счётчиком, списком найденных объектов и кнопкой удаления.

Фото уменьшается до 1024 пикселей по большей стороне и сжимается в JPEG с качеством 85.
На мобильных это делает сам `image_picker`, а на компьютере пакет эти параметры игнорирует, и
ограничения применяет приложение.

Объекты распознаёт модель EfficientDet-Lite4 (int8, вход 640×640, обучена на COCO, около 42 % mAP, лицензия Apache 2.0).
Источником является [tensorflow/efficientdet](https://www.kaggle.com/models/tensorflow/efficientdet/tfLite/lite4-detection-default).
[Прямая ссылка на файл](https://tfhub.dev/tensorflow/lite-model/efficientdet/lite4/detection/default/2?lite-format=tflite).
Модель и метки лежат в `assets/models`.
В `labelmap.txt` 91 строка, из которых первая является заглушкой `???`.
Индекс класса из модели плюс один даёт номер строки.

На фото остаются пять самых вероятных объектов с вероятностью не ниже 0.3.
Рамки и подписи рисуются прямо на фото, и в Hive сохраняется уже размеченный снимок вместе со списком объектов.

## Анимация избранного

Сердце в кнопке избранного сделано на Rive.
Анимация взята из [Rive Community](https://rive.app/marketplace/1683-3324-like-button/).

## Запуск

```bash
flutter pub get
flutter run
```

Первый запуск требует интернета, так как локальная база ещё пуста, и без сети список будет пустым.
После первой успешной загрузки приложение работает и в офлайне.

Кодогенерацию адаптеров можно запустить так:

```bash
dart run build_runner build
dart format lib
```

## Тесты

Перед первым запуском тестов и после `flutter clean` нужно скачать нативную библиотеку Rive для
хоста:

```bash
dart run rive_native:setup --verbose --clean --platform macos
```

Затем:

```bash
flutter test
```

Тесты с тегом `native` запускают настоящую модель и требуют нативной библиотеки `flutter_litert` на хосте.
Без неё их можно пропустить:

```bash
flutter test --exclude-tags native
```
